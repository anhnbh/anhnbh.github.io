# 7-Day Study Plan — AIF-C01

> **Assumption:** You can commit ~**3–4 focused hours/day** (≈ 25 hours total). Adjust proportionally if you have more/less time.
> **Strategy:** Weight hours toward high-% domains. Domain 3 (28%) + Domain 2 (24%) together = **52% of the exam** — don't under-prepare these.

---

## 🗓️ Day-by-day schedule

### **Day 1 — Foundations & Domain 1 (AI/ML basics)**
**Goal:** Solidify ML vocabulary + lifecycle. ~3.5h

| Block | Time | Task |
|---|---|---|
| ☐ Warm-up | 30 min | Read `README.md` + official [exam guide](https://docs.aws.amazon.com/aws-certification/latest/ai-practitioner-01/ai-practitioner-01.html) — note domain weights |
| ☐ Theory | 90 min | Read `01-domain1-ai-ml-fundamentals.md` (full) |
| ☐ AWS tie-in | 30 min | Skim: SageMaker overview page, "What is ML?" AWS docs |
| ☐ Active recall | 30 min | Flashcards section "D1" in `07-flashcards.md` |
| ☐ Mini-quiz | 30 min | Do Domain 1 questions in `06-mock-questions.md` |

**✅ Verify:** Can you explain supervised vs. unsupervised vs. RL in 1 sentence each, and name the 6 stages of the ML lifecycle?

---

### **Day 2 — Domain 2 (GenAI fundamentals)**
**Goal:** Understand LLMs, tokens, embeddings, prompts. ~3.5h

| Block | Time | Task |
|---|---|---|
| ☐ Theory | 90 min | Read `02-domain2-genai-fundamentals.md` (full) |
| ☐ Deep dive | 45 min | Watch: AWS "Generative AI with Amazon Bedrock" overview video (YouTube) |
| ☐ Practice | 30 min | Use Amazon Bedrock playground (free tier) — try different prompts |
| ☐ Active recall | 30 min | Flashcards "D2" |
| ☐ Mini-quiz | 45 min | Domain 2 questions |

**✅ Verify:** Can you explain RAG, fine-tuning, and prompt engineering — and when to use each?

---

### **Day 3 — Domain 3 part 1 (Foundation models + Bedrock)**
**Goal:** Master Bedrock model selection & basic invocation. ~4h

| Block | Time | Task |
|---|---|---|
| ☐ Theory | 90 min | Read `03-domain3-foundation-models.md` — sections: Bedrock, model selection |
| ☐ Hands-on | 60 min | Bedrock playground: invoke Titan, Claude, Llama; compare outputs |
| ☐ Knowledge base | 45 min | Try Bedrock Knowledge Bases (upload a PDF, ask questions) — RAG in action |
| ☐ Active recall | 30 min | Flashcards "D3" |
| ☐ Mini-quiz | 45 min | Domain 3 questions (first half) |

**✅ Verify:** Can you pick the right Bedrock model for: (a) summarization, (b) code generation, (c) embeddings, (d) multimodal?

### **Day 4 — Domain 3 part 2 (SageMaker + customization)**
**Goal:** Know SageMaker's role + model customization options. ~3.5h

| Block | Time | Task |

### **Day 6 — Full mock exam**
**Goal:** Simulate exam conditions. ~3h

| Block | Time | Task |
|---|---|---|
| ☐ Mock exam | 90 min | Do **all** of `06-mock-questions.md` in one sitting, no notes, timer on |
| ☐ Score & review | 90 min | Mark wrong answers → re-read the relevant cheat sheet section for each |

**✅ Verify:** Did you score ≥ 75%? If yes → you're on track. If < 70% → focus Day 7 on weak domains.

---

### **Day 7 — Review & drill**
**Goal:** Solidify weak spots + speed. ~3h

| Block | Time | Task |
|---|---|---|
| ☐ Flashcards drill | 60 min | All flashcards in `07-flashcards.md`, 2 passes |
| ☐ Weak domain review | 90 min | Re-read cheat sheets for domains where mock score was lowest |
| ☐ Exam logistics | 30 min | Confirm: exam date, location/login, ID requirements, what to bring |

**✅ Verify:** You can answer any flashcard in < 5 seconds. You're ready.
