## 🎯 Exam at a glance

- **5 domains** — focus first on Domain 3 (28%) + Domain 2 (24%) = **52% of the exam**.
- **Foundational level** — no hands-on required, but you must know AWS service *names*, *use cases*, and *differentiators* cold.
- **High-yield services:** Amazon Bedrock, Amazon SageMaker, Amazon Q, Amazon Comprehend, Amazon Rekognition, Amazon Transcribe, Amazon Polly, Amazon Lex, Amazon Titan, AWS HealthScribe.
- **Common traps:** confusing SageMaker managed service vs. Bedrock serverless; RAG vs. fine-tuning; prompt engineering vs. RLHF; data in transit vs. at rest.
