🌍 Global vs Regional (Classic CLF Question)

ConceptKey Facts
Global servicesIAM, Route 53, CloudFront, WAF, Shield, Organizations, Billing
Regional servicesEC2, S3 (regional but global namespace), RDS, Lambda, DynamoDB (regional, global tables optional)
AZ conceptOne or more discrete data centers in a Region; isolated from failures in other AZs
Region choice factorsLatency, cost, compliance/data residency, service availability

🔥 High-Frequency Services — One-Liners

IAM

Users, groups, roles, policies. Global. MFA + least privilege. Root = only for billing.

Amazon EC2

Virtual servers. On-Demand, Reserved, Spot, Savings Plans. Scale with ASG.

Amazon S3

Object storage, 11 nines durability. Standard / IA / One-Zone IA / Glacier tiers.

Amazon RDS

Managed relational DBs. Multi-AZ = HA; Read Replicas = read scaling.

AWS Lambda

Serverless functions, 15-min max, pay-per-invocation. No infra to manage.

CloudWatch

Metrics, logs, alarms, dashboards. AWS-native monitoring default answer.

CloudTrail

API call audit log. "Who did what when" = CloudTrail, always.

Trusted Advisor

Account-level best-practice checks: cost, performance, security, fault tolerance.

Cost Explorer

Visualize/forecast spend over time. Budgets = alerts on thresholds.

AWS Organizations

Multi-account management, SCPs, consolidated billing (one bill).

Route 53

Global managed DNS. Latency / failover / geolocation routing policies.

Shield + WAF

Shield = DDoS (Standard free / Advanced paid). WAF = L7 firewall rules.
